# P3 — Base do front (Next.js 16): plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar `web/` com toda a infraestrutura que não depende do visual: rotas localizadas pt/en, cliente tipado da API, cache com revalidação, SEO técnico, segurança, formulários e esqueleto funcional de todas as páginas.

**Architecture:** Next.js 16 App Router com Server Components por padrão. `next-intl` 4 controla idioma e caminhos traduzidos (rotas internas em inglês). Dados só pela API Laravel (`docs/api.md`), buscados no servidor com `fetch` + tags de cache; o Laravel dispara `/api/revalidate`. Formulários e link de download falam direto com a API pelo navegador. Imagens usam `<img srcset>` nativo a partir das conversões da API (sem otimizador da hospedagem). O visual final vem do plano P4, depois da direção de arte aprovada: aqui o markup é semântico e mínimo.

**Tech Stack:** Node 24, pnpm 11, Next.js 16, React 19, TypeScript, Tailwind CSS 4, next-intl 4, zod, Vitest, ESLint (config do Next), Prettier + prettier-plugin-tailwindcss, @google/model-viewer.

**Spec:** [docs/specs/2026-09-23-fundacao-design.md](../specs/2026-09-23-fundacao-design.md) — contrato em [docs/api.md](../api.md).

- [ ] **Step 5: `web/src/lib/env.ts`**

```ts
import { z } from 'zod';

const bool = z
  .enum(['true', 'false', '1', '0'])
  .optional()
  .transform((value) => value === 'true' || value === '1');

const serverSchema = z.object({
  API_URL: z.url(),
  FRONTEND_API_KEY: z.string().min(1).optional(),
  SITE_URL: z.url(),
  SITE_ENV: z.enum(['local', 'staging', 'production']).default('local'),
  REVALIDATE_SECRET: z.string().min(1).optional(),
  STAGING_BASIC_AUTH_USER: z.string().min(1).optional(),
  STAGING_BASIC_AUTH_PASSWORD: z.string().min(1).optional(),
  ALLOW_BUILD_WITHOUT_API: bool,
});

const publicSchema = z.object({
  NEXT_PUBLIC_API_URL: z.url(),
  NEXT_PUBLIC_SITE_LOCALES: z
    .string()
    .default('pt,en')
    .transform((value) =>
      value
        .split(',')
        .map((locale) => locale.trim())
        .filter(Boolean),
    )
    .pipe(z.array(z.enum(['pt', 'en'])).min(1)),
  NEXT_PUBLIC_TURNSTILE_SITE_KEY: z.string().min(1).optional(),
});

export type ServerEnv = z.infer<typeof serverSchema>;
export type PublicEnv = z.infer<typeof publicSchema>;

export function parseServerEnv(source: Record<string, string | undefined>): ServerEnv {
  return serverSchema.parse(source);
}

export function parsePublicEnv(source: Record<string, string | undefined>): PublicEnv {
  return publicSchema.parse(source);
}

export function serverEnv(): ServerEnv {
  return parseServerEnv(process.env);
}

export const publicEnv: PublicEnv = parsePublicEnv({
  NEXT_PUBLIC_API_URL: process.env.NEXT_PUBLIC_API_URL,
  NEXT_PUBLIC_SITE_LOCALES: process.env.NEXT_PUBLIC_SITE_LOCALES,
  NEXT_PUBLIC_TURNSTILE_SITE_KEY: process.env.NEXT_PUBLIC_TURNSTILE_SITE_KEY,
});
```

(As variáveis `NEXT_PUBLIC_*` precisam ser lidas por nome literal para o Next embutir no bundle do navegador. Se `z.url()` não existir na versão do zod instalada, use `z.string().url()`.)
