# P1 — Fundação do monorepo: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deixar a raiz do monorepo pronta para `api/` e `web/` se encaixarem: normalização de linha, workspace pnpm, hooks de commit, compose do banco, metadados do GitHub, configuração do Claude Code, ADRs e README.

**Architecture:** Raiz é um workspace pnpm (só `web/` como pacote Node). Hooks husky chamam lint-staged, que usa a config mais próxima de cada arquivo (cada app terá a sua). CI fica em um workflow por app, criado nos planos P2 e P3.

**Tech Stack:** pnpm 11, husky 9, lint-staged 17, commitlint, Prettier 3, Docker Compose (MySQL 8.4, Mailpit).

**Spec:** [docs/specs/2026-09-23-fundacao-design.md](../specs/2026-09-23-fundacao-design.md)

## Global Constraints

- Node 24 LTS, pnpm 11 (`packageManager: pnpm@11.8.0`).
- Commits em Conventional Commits, mensagem em português, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Nada de segredo versionado; `.env` e variantes continuam ignorados pelo `.gitignore` existente.
- Texto de docs em português; nomes de arquivo, chaves e código em inglês.
- Não criar nada dentro de `api/` ou `web/` neste plano (exceto manter os README existentes).

### Task 3: Banco local em Docker

**Files:**
- Create: `compose.yaml`, `docker/mysql/create-testing-database.sh`

- [ ] **Step 1: `compose.yaml`**

```yaml
name: franccino

services:
  mysql:
    image: mysql:8.4
    restart: unless-stopped
    ports:
      - '${FORWARD_DB_PORT:-3306}:3306'
    environment:
      MYSQL_DATABASE: franccino
      MYSQL_USER: franccino
      MYSQL_PASSWORD: secret
      MYSQL_ROOT_PASSWORD: secret
    volumes:
      - mysql-data:/var/lib/mysql
      - ./docker/mysql/create-testing-database.sh:/docker-entrypoint-initdb.d/10-create-testing-database.sh:ro
    healthcheck:
      test: ['CMD', 'mysqladmin', 'ping', '-h', 'localhost', '-psecret']
      interval: 5s
      timeout: 5s
      retries: 20

  mailpit:
    image: axllent/mailpit:latest
    restart: unless-stopped
    ports:
      - '${FORWARD_MAILPIT_PORT:-1025}:1025'
      - '${FORWARD_MAILPIT_DASHBOARD_PORT:-8025}:8025'

volumes:
  mysql-data:
```

- [ ] **Step 2: `docker/mysql/create-testing-database.sh`**

```sh
#!/usr/bin/env sh
set -e
mysql --user=root --password="$MYSQL_ROOT_PASSWORD" <<-EOSQL
  CREATE DATABASE IF NOT EXISTS franccino_testing;
  GRANT ALL PRIVILEGES ON franccino_testing.* TO '$MYSQL_USER'@'%';
EOSQL
```

- [ ] **Step 3: Validar sintaxe**

Run: `node -e "const s=require('fs').readFileSync('compose.yaml','utf8'); if(!/services:/.test(s)) process.exit(1); console.log('ok')"` e, se Docker existir, `docker compose config -q`.
Expected: `ok` (Docker ainda não instalado nesta máquina; validação completa fica para quem tiver Docker).

- [ ] **Step 4: Commit**
